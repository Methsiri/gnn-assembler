# samples

Small assemblies used by the tests and by a first `plan` or `train` run. They are generated by `gnn-assemble generate-samples` and checked in so the commands work without that step.

Each child folder is one assembly. Parts are `.obj` meshes already posed in the assembled frame. `assembly.json` sets the id, mass, and the axis-aligned boxes used for collision. Joint lines are hints. When they are omitted, the contact graph infers the joint.

| Folder | Id | What it is |
| --- | --- | --- |
| `peg_hole` | `peg_hole` | A peg standing in an open pocket. It lifts out along Z, then the base is free. |
| `rotational` | `rotational` | A collar on a shaft. A tooth blocks a straight lift, so the collar turns and then lifts. |
| `multi_stack` | `stack` | Three blocks. Removal order is `top`, `mid`, `base`. |

```bash
gnn-assemble plan --dir samples --id stack --output stack.3mf
```

These are not the research datasets. Put `joint_assembly.zip` under `data/` at the repository root.
